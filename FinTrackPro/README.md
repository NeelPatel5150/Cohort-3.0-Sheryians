# FinTrack Pro

Simple expense tracker project made with HTML, CSS and JavaScript.

## Features
- Add income and expense
- Edit and delete transaction
- LocalStorage save/load
- Search and filter
- Monthly chart with Chart.js
- Dark mode
- Currency switch (INR, USD, EUR)

## Files
- `index.html`
- `style.css`
- `script.js`

## Run
Open `index.html` in browser.

## Notes
This project is built in a simple student-friendly coding style (normal functions, loops, if/else).
